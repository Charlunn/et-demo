# ADR 0001 · SCED LP 取对偶当 LMP, 不做 UC 整数

## 状态
Accepted

## 背景
demo 要展示日前联合出清 (能量 + 1 个旋转备用) 并产出"真实可信"的节点 LMP(能量价/阻塞价/损耗价).
可选路: (A) 固定机组组合的经济调度 (SCED) 是一个 LP; (B) 含开停机的机组组合 (SCUC) 是 MILP.

## 决策
选 (A) LP-SCED, 求解后**直接读节点功率平衡约束的对偶变量**作为该节点 LMP.
- 阻塞价 = 负荷节点 LMP − 参考节点 LMP (线路限流制造阻塞时 > 0).
- 损耗价 = 0 (注释: 生产才计).
不做 UC 整数搜索.

## 理由
- LMP 真实性来自"约束的影子价", 与是否含整数开停机无关: 固定组合下 LP 的对偶仍然给出正确的
  边际节点价. UC 只决定当日启停哪些机组, 不改变"给定组合下最优调度的影子价"含义.
- 1h demo 范围内 MILP 求解器不稳且对领域可信度无增益; 纯 Python `pulp` + CBC LP 装得稳、
  求得快, 对偶变量可直接读.
- 短路电价 (LMP uniform) 不混说: LMP 按节点分解, 阻塞时两节点差值即阻塞分量.

## 后果
- 正面: 代码简洁、可手算对照 (阻塞例 congestion>0 由受限线路推出), 出清测试可独立验证.
- 负面/边界: 不展示开停机决策; 若面试官追问"夜间停某机组"的 UC, 说明 SCED 是 demo 取舍层,
  真平台 SCUC 另走 MILP; LMP 的经济含义依然成立.
