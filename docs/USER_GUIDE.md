# 使用手册 · spark-pricing 产品工作台

> 面向**电力交易员 / 分析师 / 结算员 / 调度**. 这是一个业务工作台, 不需要懂 API 或写代码. 打开浏览器即可走完"看行情 → 做报价 → 看出清 → 对账 → 复盘"整条业务路径.

---

## 1. 登录

浏览器打开工作台地址 (本地 `http://localhost:8501`, 生产为你司域名).

- 默认 demo 凭据: 用户名 `trader` / 密码 `trader-secret` (生产由管理员配置).
- 登录后顶部显示当前用户徽标与"合成数据"状态徽标 (提示当前为可复现演示数据).
- 左侧边栏是五个业务页导航, 按业务动作顺序排列.

---

## 2. 五个业务页

### 2.1 行情看板 📈 (交易员 / 分析师)

**来干什么**: 看当前电价和历史走势, 判断市场态势.

操作:
1. 选**节点** (REF 参考节点 / LOAD 负荷节点 / 全部) 和**时段范围** (24–288 段).
2. 看三张 KPI 卡: 区间均价 / 最高 / 最低, 以及阻塞时段数.
3. 多节点 LMP 折线图: 红色虚线标出阻塞时段.
4. 负荷日内分布柱状图.
5. 点"下载 csv"导出本段行情.

**怎么读**: 负荷节点 LMP 明显高于参考节点 = 出现阻塞 (便宜的基荷电被输电线路卡住, 负荷侧被迫用贵电).

---

### 2.2 报价工作台 🧮 (交易员)

**来干什么**: 给手里的机组做一份分段报价, 提交进待出清队列.

操作:
1. 选**机组**, 上方看它的边际成本曲线小图.
2. 选**报价策略**:
   - *报边际成本* (基线): 按机组真实边际成本报价.
   - *边际成本 + 预测加成*: 结合 LMP 预测调整报价阶梯.
3. 拖**风险加成**滑杆 (元/MWh), 下方分段报价表实时重算 (最多 10 段, 每段一个价/量).
4. 确认后点"提交报价", 报价进入待出清队列.

**注意**: 你只需选策略和调参数, 报价曲线由系统按成本 + 策略自动生成 — 不需要手填任何数字表格或 JSON.

---

### 2.3 出清与计划 ⚙️ (调度 / 交易)

**来干什么**: 触发日前出清, 查看每台机组的出力计划和节点电价.

操作:
1. 设**时段数** / **线路潮流上限** / **数据来源天数**.
2. 点"运行出清", 等待求解 (能量 + 旋转备用 联合优化).
3. 结果看:
   - 每节点 **LMP 卡片**, 拆成能量价 / 阻塞价 / 损耗价.
   - **2 节点拓扑图**: 输电线满载时标红 (表示阻塞).
   - 每台机组的**出力 P 与旋转备用 R** 表.
   - **时段下钻**: 拖滑杆看任意时段的电价与调度.

**怎么读**: 阻塞价 > 0 说明该时段线路满载; 调小"线路潮流上限"可以人为制造/加剧阻塞观察效果.

---

### 2.4 结算对账 🧾 (结算员)

**来干什么**: 算本周期该收该付款, 生成结算单.

操作:
1. 输入**日前计划电量 / 实际电量 / 日前 LMP / 实时 LMP**.
2. (可选) 启用**中长期差价合约 (CfD)**, 填合约价 / 合约量 / 参考价.
3. 点"运行三层结算", 看:
   - **日前结算** = 计划电量 × 日前 LMP
   - **实时偏差** = (实际 − 计划) × 实时 LMP (只对偏差电量计, 避免双重计价)
   - **中长期差价** = (合约价 − 参考价) × 合约量
   - **合计**大数 + "与手算口径一致"绿勾标注.
4. 点"导出结算单 (csv)".

---

### 2.5 回测复盘 📊 (分析师 / 交易员)

**来干什么**: 对比两条报价策略在历史上的业绩, 出一份复盘报告.

操作:
1. 选**回测天数** / **线路潮流上限** / **待测策略的预测模型**.
2. 点"运行回测", 看:
   - **双 PnL 累计曲线**: 基线 (报边际成本) vs 待测 (边际成本 + 预测加成).
   - **六项指标对照表**: 总收益 / 命中率 / 盈亏比 / 信息比率 / 出清价 MAPE / 最大回撤.
   - **中文自然语言小结**: 程序生成, 诚实标注哪些模型真跑 (Persistence/XGBoost) 哪些是 stub (LSTM).
3. 点"导出复盘报告 (csv)".

**诚实提示**: 预测模型选 `lstm` 时是占位 stub (返回 persistence 结果), 报告会明确标注, 不会把它当真实结果展示.

## 3. 常见问题

| 问题 | 说明 |
|---|---|
| 登录后操作提示"后端不可达" | 后端服务未启动或网络问题, 联系运维 |
| 出清提示"无可行解" | 线路上限太小 / 负荷太高导致约束冲突, 放宽"线路潮流上限"再试 |
| 操作太频繁被拦 | 后端有限流保护, 稍等再试 |
| 数据是真实市场吗? | 否. 当前为固定随机种子生成的**可复现合成行情**, 用于演示与回测; 顶部"合成数据"徽标已标注 |
| 会话过一会失效 | JWT 令牌有有效期 (默认 60 分钟), 重新登录即可 |

## 4. 术语速查

| 术语 | 含义 |
|---|---|
| LMP | 节点边际电价 = 能量价 + 阻塞价 + 损耗价 |
| 出清 | 用优化 (LP) 决定各机组出力, 电价取自约束的对偶变量 |
| 阻塞 | 输电线路满载, 导致两节点电价出现差值 |
| 旋转备用 | 预留的可快速调用发电容量 |
| 双结算 | 日前结算 + 实时偏差结算两笔 |
| CfD | 中长期金融差价合约, 与物理交割解耦 |
| PnL | 盈亏 (Profit and Loss) |
